Test your Morse code knowledge! This game will play a Morse code sequence, and you need to identify which letter it represents.

Listen carefully to the dots and dashes, then type the corresponding letter.

Game Rules:

  • You have 60 seconds to answer as many questions as possible
  • The game ends when the timer reaches 0
  • Points per correct answer:
    • Letters Only: 1 point
    • Letters + Numbers: 2 points
    • Letters + Numbers + Punctuation: 3 points
